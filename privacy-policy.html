Kebijakan Privasi & Keamanan Data (Data Safety)

Kebijakan Privasi

Aplikasi: Al Quran Digital Indonesia (com.mashendig17al.quranpro)
Pengembang: Hendra Setiawan (@mashendig17al) • Terakhir Diperbarui: November 2026

🛡️ 1. Komitmen Privasi Utama: Zero Data Collection

Aplikasi Al Quran Digital Indonesia dirancang dengan memprioritaskan privasi dan ketenangan beribadah pengguna. Kami TIDAK PERNAH mengumpulkan, mencatat, memperjualbelikan, atau membagikan data identitas pribadi pengguna ke server manapun.

  • Bebas Iklan (Ad-Free): Tidak ada SDK periklanan atau ID pelacak iklan (Advertising ID).
  • Bebas Pelacak (Zero Trackers / No Analytics): Tidak ada integrasi analitik pihak ketiga (seperti Google Analytics, Firebase Analytics, Facebook SDK, dsb.).
  • Tanpa Akun Pengguna: Aplikasi dapat digunakan langsung tanpa perlu membuat akun, login, atau memberikan email/nomor ponsel.

🌐 2. Transparansi Penggunaan API Pihak Ketiga & Audio CDN

Untuk melengkapi data 114 surat dan lantunan murottal audio yang diunduh atas inisiatif pengguna, aplikasi berinteraksi dengan layanan pihak ketiga melalui protokol HTTPS aman:

  • Layanan API Al-Qur'an (equran.id): Teks ayat dan terjemahan Bahasa Indonesia yang diunduh secara online diambil melalui REST API terbuka yang disediakan secara independen oleh komunitas pengembang equran.id (mengacu pada standar terjemahan dan susunan Mushaf Standar Indonesia Kemenag RI). Aplikasi tidak mengirimkan informasi profil pengguna saat melakukan permintaan HTTP GET ke API tersebut.
  • CDN Murottal Audio (EveryAyah.com & QuranCDN): Berkas audio murottal per ayat diunduh dari repositori publik terpercaya (seperti everyayah.com dan cdn.equran.id). Permintaan hanya meminta file audio statis (.mp3) tanpa melampirkan token atau data pengenal pengguna.

💾 3. Data yang Disimpan Secara Eksklusif di Perangkat (Lokal)

Seluruh riwayat dan preferensi pengguna disimpan 100% di memori perangkat lokal pengguna (IndexedDB & LocalStorage):

  • Teks Surat & Terjemahan: Tersimpan di IndexedDB QuranOfflineDB agar dapat dibaca selamanya tanpa internet.
  • Audio Murottal Offline: File audio yang berhasil diunduh disimpan dalam bentuk Blob terisolasi di IndexedDB QuranAudioDB.
  • Penanda Terakhir Baca & Bookmark: Tersimpan di LocalStorage lokal untuk memudahkan melanjutkan membaca.
  • Preferensi Pengguna: Pilihan qari, ukuran font, tema gelap/terang, dan opsi tajwid.

🔐 4. Izin Akses Android (Permissions) & Tujuannya

Aplikasi ini hanya meminta izin yang mutlak diperlukan untuk fungsionalitas ibadah, sesuai dengan kebijakan Google Play Store:

  • INTERNET & ACCESS_NETWORK_STATE: Diperlukan saat pertama kali mengunduh teks surat atau audio murottal dari layanan API / CDN pihak ketiga. Setelah diunduh, aplikasi beroperasi penuh secara luring (100% offline).
  • POST_NOTIFICATIONS (Android 13+): Digunakan untuk menampilkan pengingat waktu sholat (Subuh, Dzuhur, Ashar, Maghrib, Isya) di status bar ponsel. Pengguna dapat mematikan izin ini kapan saja di menu Pengaturan.
  • USE_EXACT_ALARM: Digunakan secara eksklusif untuk membunyikan pengingat jadwal sholat tepat pada waktunya sesuai perhitungan hisab Indonesia (kategori Alarms & Timers kebijakan Google Play).
  • RECEIVE_BOOT_COMPLETED: Digunakan untuk mendaftarkan ulang jadwal pengingat sholat secara otomatis setelah ponsel dinyalakan ulang (reboot).
  • VIBRATE & WAKE_LOCK: Digunakan sesaat ketika alarm jadwal sholat berbunyi agar pengguna tidak melewatkan waktu ibadah.

🗑️ 5. Kontrol Pengguna & Penghapusan Seluruh Data Lokal

Pengguna memiliki kendali mutlak untuk menghapus data dari perangkat mereka kapan saja:

  • Tombol Hapus Semua Data Lokal di Aplikasi: Di menu Pengaturan ➔ Privasi & Keamanan Data, tersedia tombol Reset / Bersihkan Semua Data Lokal yang akan langsung menghapus seluruh database IndexedDB (teks 114 surat dan file murottal yang telah diunduh) serta membersihkan LocalStorage.
  • Penghapusan melalui Pengaturan Sistem Android: Pengguna dapat memilih menu Info Aplikasi ➔ Hapus Penyimpanan (Clear Storage) atau menghapus (uninstall) aplikasi untuk menghapus seluruh data tanpa sisa di perangkat.
